# 한자 쪼개 보기 (hanja-split)

한자를 부수·조각으로 쪼개 보고, 급수 한자를 뽑아 측자(測字) 풀이 프롬프트를 만드는 단일 HTML 앱.

- 사이트: https://hanja-split-v5.pages.dev
- 파일: `index.html` 하나에 데이터와 스크립트가 모두 들어 있다. 빌드 과정은 없다.

## 풀이 프롬프트가 쓰는 근거

- 옛 측자서의 처리 원칙(『측자전서』 측자수지): 글자 전체를 먼저 보고 분해는 질문과 맞을 때만, 관련 있는 첨가만, 길흉이 섞이면 무거운 쪽.
- 질문 갈래별 길흉 신호 글자(제사논단결·測字應變法)와 먼저 물어볼 것.
- 글자별 문헌 근거(`EVID`, 1,582자): 원문 판어·취격 문구·옛 사례를 질문 갈래에 맞춰 골라 넣는다. 이체자 25쌍(腳→脚 등)을 이어 붙인다. 근거는 연구 보관함의 구조화 데이터에서 내보낸 축약본이며, 질문 갈래 대응은 편집자 처리다.

점괘는 전통 글자점으로 재미 삼아 보는 풀이이며, 옛 책의 판어는 맞는다는 보증이 아니다.
